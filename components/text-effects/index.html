GLITCH

Glitch Effect

glitch cyber
CSS 
.text-glitch {
  color: #fff;
  position: relative;
}
.text-glitch::before,
.text-glitch::after {
  content: attr(data-text);
  position: absolute;
  top: 0; left: 0;
}
.text-glitch::before {
  color: #ff0000;
  animation: glitch-1 0.3s infinite alternate;
  clip-path: polygon(0 0, 100% 0, 100% 35%, 0 35%);
}
.text-glitch::after {
  color: #00ffff;
  animation: glitch-2 0.3s infinite alternate;
  clip-path: polygon(0 65%, 100% 65%, 100% 100%, 0 100%);
}
