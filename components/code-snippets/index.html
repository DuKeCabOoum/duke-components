Numbered Lines

Blocs de code avec numéros de ligne.

python
1 2 3 4 5 6
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))  # Output: 55
