Basic Tooltip

CSS Only Simple
CSS 
.tooltip__content {
  position: absolute;
  bottom: calc(100% + 10px);
  left: 50%;
  transform: translateX(-50%) scale(0.9);
  opacity: 0;
  visibility: hidden;
  transition: all 0.2s ease;
}

.tooltip:hover .tooltip__content {
  opacity: 1;
  visibility: visible;
  transform: translateX(-50%) scale(1);
}
