Slide Up Modal

Mobile Bottom Sheet
CSS 
.modal-slide {
  position: fixed;
  bottom: 0;
  left: 50%;
  transform: translateX(-50%) translateY(100%);
  transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1);
}

.modal-overlay--active .modal-slide {
  transform: translateX(-50%) translateY(0);
}
